# Telegram-бот для розподілу ставки за кілометражем

Бот:

- приймає ставку в USD або EUR, місто завантаження, пункт пропуску та місто вивантаження;
- отримує офіційний курс із API Національного банку України;
- знаходить два автомобільні відрізки: до кордону та після кордону;
- ділить ставку пропорційно кілометражу;
- показує обидві частини у валюті та гривнях;
- у ручному режимі ділить ставку за вже погодженими кілометрами.

## Приклади команд

```text
/calc 3400 USD | Гданськ | Ягодин | Київ
/calc 2800 EUR | Роттердам | Ужгород | Одеса
/manual 3400 USD | 720 | 510
/rate
/id
```

Замість `USD` можна написати `$` або `дол`, замість `EUR` — `€` або `євро`.

## Що потрібно

- Telegram-токен від [@BotFather](https://t.me/BotFather);
- акаунт GitHub;
- акаунт Railway.

Для цього бота **не потрібні** `API_ID`, `API_HASH` або `SESSION_STRING`. Він працює через звичайний Telegram Bot API.

## Запуск через GitHub і Railway

1. У Telegram відкрийте `@BotFather`, виконайте `/newbot` і скопіюйте токен.
2. Створіть новий порожній репозиторій на GitHub.
3. Завантажте в корінь репозиторію всі файли з цієї папки. `bot.py`, `Dockerfile` і `requirements.txt` мають лежати саме в корені.
4. У Railway натисніть **New Project → Deploy from GitHub repo** і виберіть цей репозиторій.
5. Відкрийте **Variables** та додайте:

   ```text
   BOT_TOKEN=токен_від_BotFather
   HTTP_USER_AGENT=nbu-route-split-bot/1.0 (contact: ваша_пошта)
   CONTACT_EMAIL=ваша_пошта
   ```

6. Щоб бот був приватним, спочатку залиште `ALLOWED_USER_IDS` порожнім, запустіть бот і надішліть `/id`. Потім додайте отримане число в Railway:

   ```text
   ALLOWED_USER_IDS=123456789
   ```

   Для кількох користувачів: `123456789,987654321`.
7. Railway автоматично збере Docker-образ і запустить команду `python bot.py`. У Telegram натисніть **Start**.

## Локальна перевірка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export BOT_TOKEN='ваш_токен'
python bot.py
```

Тести без зовнішніх API:

```bash
python -m unittest discover -s tests -v
```

## Звідки беруться дані

- Курс: офіційний API НБУ.
- Пошук населених пунктів і переходів: Nominatim/OpenStreetMap.
- Автомобільна відстань: OSRM/OpenStreetMap.

У коді є пауза не менше однієї секунди між запитами до публічного Nominatim, кешування однакових пошуків, окремий `User-Agent` та атрибуція. Публічні Nominatim і OSRM підходять для невеликого особистого бота, але не мають гарантії доступності для комерційного навантаження. Для більшого навантаження задайте в Railway власні або платні сумісні адреси через `NOMINATIM_URL` та `OSRM_URL`.

## Важливо для рахунків

Онлайн-маршрут може відрізнятися від кілометражу, погодженого з бухгалтерією, замовником або зазначеного у транспортних документах. Бот завжди показує, які саме точки він знайшов. Якщо для рахунку вже затверджено кілометри, використовуйте `/manual` — тоді розподіл буде зроблено саме за ними.
